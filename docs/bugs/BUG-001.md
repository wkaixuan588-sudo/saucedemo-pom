# BUG-001 部分商品点击加购后无任何反馈，购物车数量不变（静默失败）

| 项目 | 内容 |
|---|---|
| 缺陷编号 | BUG-001 |
| 所属模块 | 购物车 / 库存页加购功能 |
| 严重程度 | **严重（Critical）** |
| 优先级 | P0 |
| 状态 | Open（站点内置演示缺陷，用于展示缺陷管理流程） |
| 发现方式 | 自动化用例固化（`tests/test_cart.py::test_error_user_add_to_cart_silently_fails`） |
| 影响账号 | error_user |

## 环境与前置条件

- 站点：https://www.saucedemo.com/（React SPA）
- 浏览器：Chromium 1243（Playwright 1.63.0 内置版本）
- 账号：error_user / secret_sauce
- 前置：使用该账号成功登录，购物车为空

## 复现步骤

1. 以 error_user 登录进入商品列表页；
2. 点击 "Sauce Labs Backpack" 的 **Add to cart**（对照组）；
3. 点击 "Sauce Labs Bolt T-Shirt" 的 **Add to cart**；
4. 观察：购物车角标数量、页面是否出现任何错误提示。

## 预期结果

每次点击 Add to cart 后：购物车角标 +1；若加购失败，应有明确的错误提示（横幅/toast）。

## 实际结果（自动化实测）

| 商品 | 点击后角标 | 错误提示 |
|---|---|---|
| Sauce Labs Backpack（对照） | 0 → 1 ✅ | 无 |
| Sauce Labs Bolt T-Shirt | 1 → **1（不变）** ❌ | **无（静默失败）** |

- 连续实测 3 款商品存在该问题：`sauce-labs-bolt-t-shirt`、`sauce-labs-fleece-jacket`、`test.allthethings()-t-shirt-(red)`；
- 全程无错误横幅（`[data-test="error"]` 不存在）、无控制台报错、按钮可正常点击——用户**完全无法感知加购未生效**。

## 证据

- 截图：`docs/bugs/evidence/bug-001-error-user-badge.png`（连续点击 2 次加购，角标仍为 1）
- 自动化数据采集：`scripts/find_defects.py` 输出 `BUG-001_error_user_silent_add_failure`
- 回归用例：`pytest tests/test_cart.py -k error_user`

## 风险与建议

- 静默失败比报错更危险：用户以为已加购，结算时才发现商品缺失，直接造成订单损失；
- 建议：加购操作应与后端状态强一致，失败路径必须有用户可感知的反馈并记录日志；
- 测试策略：本缺陷已固化为负向回归用例，防止"修复后回归"时误删断言。
