# BUG-003 购物车图标错位，与商品排序下拉框重叠

| 项目 | 内容 |
|---|---|
| 缺陷编号 | BUG-003 |
| 所属模块 | 库存页头部布局（UI） |
| 严重程度 | 一般（Minor） |
| 优先级 | P2 |
| 状态 | Open |
| 发现方式 | 自动化探测脚本（`scripts/find_defects.py`，几何坐标对比法） |
| 影响账号 | visual_user |

## 环境与前置条件

- 浏览器：Chromium 1243 / 视口 1280×800
- 账号：visual_user / secret_sauce

## 复现步骤

1. 分别以 standard_user 和 visual_user 登录进入商品列表页；
2. 对比两账号下购物车图标（右上角）的位置；
3. 检查图标与商品排序下拉框（右侧）的相对位置关系。

## 预期结果

两账号下头部布局一致：购物车图标位于右上角，不与其他控件重叠。

## 实际结果（自动化实测，bounding box 几何数据）

| 元素 | standard_user | visual_user | 偏移 |
|---|---|---|---|
| 购物车图标 | x=1220, y=10, 40×40 | x=1034, y=39, 42×42 | **dx=-186px, dy=+29px** |
| 排序下拉框 | x=1036, y=70, 223×30 | 同左 | — |

- 购物车图标左移 186px、下移 29px；
- 图标区域 [1034,39,42×42] 与排序下拉框 [1036,70,223×30] **重叠约 441px²**，
  图标压在排序控件上方，可能遮挡其点击热区。

## 检测方法说明

未使用截图肉眼比对，而是**同视口下两账号的同元素几何坐标对比 + 矩形重叠判定**——
可量化、可复现、可直接进 CI（几何断言不依赖图像基线，无环境噪声）。

## 证据

- 整页截图：`docs/bugs/evidence/bug-003-visual-user-inventory.png`
- 头部特写：`docs/bugs/evidence/bug-003-visual-user-header-zoom.png`（图标与下拉重叠细节）
- 自动化数据采集：`scripts/find_defects.py` 输出 `BUG-003_visual_user_layout`
  （`overlaps_sort_dropdown: true, overlap_area_px: 441`）

## 风险与建议

- 图标错位遮挡排序控件热区，影响可用性；移动端小屏下遮挡会更严重；
- 建议：回归中增加关键控件几何断言（位置漂移阈值 + 与相邻控件重叠检测）。
